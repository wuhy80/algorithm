# Gray-Scott 反应扩散算法

反应扩散系统描述多种物质一边发生局部化学反应、一边在空间中扩散时产生的浓度变化。Gray-Scott 模型只使用两种虚拟物质 A 和 B，却能从均匀环境中的微小扰动自发形成斑点、条纹、分裂细胞和迷宫等复杂形态。

## 解决什么问题

反应扩散模型用于解释和生成“局部作用如何形成全局图案”，常见应用包括：

- 模拟动物皮毛、贝壳、珊瑚和细胞组织等自然纹理。
- 程序化生成游戏地图、材质、遮罩与动态视觉效果。
- 研究化学振荡、形态发生和非线性动力系统。
- 演示简单局部规则产生复杂自组织结构的过程。

它不是传统意义上的搜索或排序算法，而是一种偏微分方程的离散数值模拟。每个网格只与附近网格交换物质，因此很适合并行计算和实时可视化。

## Gray-Scott 模型

网格中保存物质 A、B 的浓度 `a` 和 `b`，每次迭代按下面的方程更新：

```text
∂a/∂t = Da · ∇²a - a·b² + F·(1-a)
∂b/∂t = Db · ∇²b + a·b² - (F+K)·b
```

其中：

- `Da`、`Db` 是两种物质的扩散系数。
- `a·b²` 表示 B 消耗 A 并复制自身的反应。
- `F` 是从外界补充 A 的速率。
- `K` 是移除 B 的速率。
- `∇²` 是拉普拉斯算子，表示当前位置和周围位置的浓度差。

极小的 F、K 变化就可能让系统进入完全不同的稳定形态。本演示提供珊瑚、细胞分裂、蠕虫、孤立波和迷宫五组经典参数，并允许实时微调。

## 本项目的实现

演示使用 Canvas 2D 和双缓冲 `Float32Array`：当前浓度写在一组数组中，每轮计算将结果写入另一组数组，然后交换引用，避免在动画循环中反复分配对象。

离散拉普拉斯算子采用九点卷积核：

```text
0.05  0.20  0.05
0.20 -1.00  0.20
0.05  0.20  0.05
```

边界使用环绕条件，画布上下和左右相连。渲染时先把浓度映射到与模拟网格同尺寸的 `ImageData`，再一次性缩放绘制到可见 Canvas；这比逐个绘制网格方块更高效。

## 交互功能

- 实时调整补给率 F、消耗率 K，以及 A、B 扩散系数。
- 调整每帧迭代次数，在演化速度和计算负载之间取舍。
- 调整模拟网格分辨率；释放滑块后重新建立网格。
- 在画布上拖动以注入物质 B，或切换为清除笔刷。
- 切换五种形态预设、暂停动画、重置初始扰动。
- 查看帧率、累计迭代次数和活跃区域比例。

## 性能与复杂度

设网格包含 `N = width × height` 个单元，每轮迭代只检查固定的八个邻居：

- 时间复杂度：每轮 `O(N)`。
- 空间复杂度：`O(N)`，四个浓度数组分别保存当前和下一状态。
- 每帧计算量：`O(N × iterationsPerFrame)`。

高分辨率和高迭代次数都会线性增加计算量。移动设备上可降低网格分辨率或每帧迭代次数，以保持流畅动画。

## 运行方式

本演示零依赖，可以直接用浏览器打开 `index.html`。也可以在本目录启动任意静态文件服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 参数观察建议

先选择一个预设，等待系统演化数百到数千轮，再用画布笔刷添加新的扰动。调整 F 或 K 时建议每次只改变 `0.001` 左右；大幅变化常会让所有 B 消失，或让反应区域充满整个网格。扩散系数之比控制边缘传播方式，而每帧迭代次数只改变观看速度，不改变模型本身的规则。
