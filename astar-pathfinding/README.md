# A* 寻路 A* Pathfinding

A* 是一种启发式图搜索算法，通过同时考虑“从起点到当前节点的实际代价”和“当前节点到终点的估计代价”，优先探索最有希望的方向。

```text
f(n) = g(n) + w × h(n)
```

其中 `g(n)` 是已知路径代价，`h(n)` 是启发式估计，`w` 是本演示可调节的启发式权重。当 `w = 0` 时算法等价于 Dijkstra；当启发函数可采纳且 `w = 1` 时，A* 可以保证找到最短路径。

## 解决什么问题

A* 常用于游戏地图导航、机器人运动规划、物流路线和网络图搜索。它利用目标方向信息减少无意义探索，在许多空间搜索问题上比无启发式搜索更高效。

## 本演示

- 动画展示开放集、已访问区域和最终路径回溯。
- 支持绘制或擦除障碍，并可移动起点和终点。
- 支持调节网格密度、障碍密度、启发式权重和每帧搜索步数。
- 可切换四方向或八方向移动；对角移动会阻止穿过障碍墙角。
