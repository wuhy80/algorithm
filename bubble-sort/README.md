# 冒泡排序（Bubble Sort）

冒泡排序反复扫描数组，比较每一对相邻元素。如果左侧元素更大，就交换两者。每轮扫描会把当前未排序部分的最大值推到右端，像气泡上浮一样逐步完成排序。

## 解决什么问题

它用于把一组可比较元素按顺序排列。冒泡排序实现简单、交换过程直观，适合教学、小规模数据和检测近乎有序的序列；面对大量数据时通常应选择快速排序、归并排序或标准库排序。

## 算法过程

```text
for end from n - 1 down to 1:
    swapped = false
    for j from 0 to end - 1:
        if array[j] > array[j + 1]:
            swap(array[j], array[j + 1])
            swapped = true
    if not swapped: break
```

本实现包含“整轮没有交换则提前结束”的优化。

## 复杂度

- 最好时间复杂度：`O(n)`，数组已有序并启用提前结束；
- 平均与最坏时间复杂度：`O(n²)`；
- 额外空间复杂度：`O(1)`；
- 稳定性：稳定，相等元素不会交换相对位置。

## 演示功能

- 随机、近乎有序和逆序数据；
- 自定义数字数组和元素数量；
- 播放、暂停、单步、速度调节和重置；
- 逐步标记比较、交换与已经就位的区间；
- 实时统计比较、交换和扫描轮次。
