# 概率动态规划 Probability DP

## 算法是什么

把状态值解释为概率分布并按随机事件转移

## 解决什么问题

计算骰子、随机游走、期望收益和有限状态随机过程的概率。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

依状态空间与事件数量而定
