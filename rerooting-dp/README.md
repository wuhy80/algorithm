# 换根动态规划 Rerooting DP

## 算法是什么

从一个根的答案沿边转移，线性求出所有根状态

## 解决什么问题

计算每个节点作为根时的子树、距离和或最优结构答案。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

通常 O(n)
