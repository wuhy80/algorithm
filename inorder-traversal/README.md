# 二叉树中序遍历 Inorder Traversal

## 算法是什么

按照左、根、右的顺序展示递归展开与节点访问

## 解决什么问题

按结构顺序遍历二叉树，并在二叉搜索树上得到递增键序列。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

时间 O(n)，递归空间 O(h)
