# 哈希表 Hash Table

哈希表通过哈希函数把键映射到数组桶位，使插入、查找和删除在平均情况下接近常数时间。它适合需要通过唯一键快速访问数据的场景。

## 解决的问题

- 字典、对象属性和数据库索引。
- 缓存、集合、计数器和去重。
- 编译器符号表与路由查找。

## 哈希与碰撞

演示使用多项式字符串哈希：依次将当前结果乘以 31，再加上字符编码，最后对桶数量取模。不同键可能映射到同一桶，这称为哈希碰撞。

本实现采用**分离链表**：每个桶保存一条键值链。定位桶后，只需要沿该链比较键。负载因子 `元素数量 / 桶数量` 越高，平均链长通常也越长。

## 复杂度

| 操作 | 平均时间 | 最坏时间 |
| --- | --- | --- |
| 插入 | O(1) | O(n) |
| 查找 | O(1) | O(n) |
| 删除 | O(1) | O(n) |
| 空间 | O(n + m) | O(n + m) |

其中 `n` 是元素数量，`m` 是桶数量。最坏情况发生在大量键集中到同一桶时。

## 演示操作

直接打开 `index.html`。输入键和值后执行插入、查找或删除；动画先展示哈希定位，再逐项扫描冲突链。可以调节桶数量、探查速度，或开启自动操作观察负载因子和碰撞数量变化。
