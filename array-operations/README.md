# 数组基本操作 Array Operations

## 算法是什么

动态展示访问、更新、插入和删除导致的元素移动

## 解决什么问题

理解顺序存储中常见操作的行为与代价，为排序和区间算法打基础。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

访问 / 更新 O(1)，插入 / 删除 O(n)
