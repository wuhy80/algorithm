# 傅里叶旋轮 Fourier Epicycles

离散傅里叶变换可以把一条闭合平面曲线分解为不同频率、振幅和相位的复指数之和。把每个复指数画成匀速旋转的向量并首尾相接，就形成“傅里叶旋轮”；最后一个向量的端点会逐步重建原始轮廓。

```text
z(t) = Σ Cₖ · e^(i·k·t)
```

## 解决什么问题

傅里叶分析用于信号处理、频谱分析、压缩、滤波、图像轮廓描述和周期系统建模。旋轮动画直观展示了复杂信号如何由简单周期分量叠加而成。

## 本演示

- 对 256 个复平面采样点执行离散傅里叶变换。
- 支持心形、星形、无穷符号、玫瑰曲线和自由手绘轮廓。
- 可调节启用项数、绘制速度、轮廓尺寸，并切换旋轮和频谱显示。
- 按振幅排序旋轮仅改变向量连接顺序，不改变最终复数和。
