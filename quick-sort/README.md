# 快速排序（Quick Sort）

快速排序是一种分治排序算法。它从当前区间选出一个枢轴（pivot），通过一次分区让较小元素移动到枢轴左侧、较大元素移动到右侧，再递归处理两侧子区间。

## 解决什么问题

快速排序用于高效地对内存中的可比较数据排序。它平均速度快、局部性好，常作为通用排序的基础；但不稳定，且不合适的枢轴可能导致极不平衡的分区。

## Lomuto 分区

本演示使用 Lomuto 分区：枢轴先放到区间末尾，指针 `j` 扫描元素，`i` 记录“小于等于枢轴”区域的末端。扫描结束后把枢轴交换到 `i + 1`。

```text
partition(low, high):
    pivot = array[high]
    i = low - 1
    for j from low to high - 1:
        if array[j] <= pivot:
            i += 1
            swap(array[i], array[j])
    swap(array[i + 1], array[high])
    return i + 1
```

页面使用显式区间栈代替语言递归，便于动画逐步展示待处理分区。

## 复杂度

- 平均时间复杂度：`O(n log n)`；
- 最坏时间复杂度：`O(n²)`；
- 平均额外空间：`O(log n)`，来自递归或显式栈；
- 稳定性：不稳定。

随机枢轴和三数取中通常能降低连续出现极端分区的概率。
