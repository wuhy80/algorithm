# 并查集 Union-Find

并查集，也称不相交集合（Disjoint Set Union，DSU），用于维护一组互不重叠的集合。它可以快速回答“两个元素是否属于同一集合”，并将两个集合合并。

## 解决的问题

- 无向图动态连通性判断。
- Kruskal 最小生成树中的环检测。
- 图像连通区域、网络分组和账户合并。
- 网格渗流及等价类维护。

## 核心操作

- `find(x)`：沿父指针找到 `x` 所属集合的根。
- `union(a, b)`：把两个根连接，从而合并集合。
- `connected(a, b)`：判断两个节点的根是否相同。

演示同时采用两种优化：按秩合并把较浅的树连接到较深的树；路径压缩在查找后让路径上的节点直接指向根。

## 复杂度

使用按秩合并和路径压缩时，连续 `m` 次操作的均摊复杂度为 `O(m α(n))`。`α(n)` 是反阿克曼函数，在实际数据规模下小于 5，因此通常可视为接近 O(1)。空间复杂度为 O(n)。

## 演示操作

直接打开 `index.html`。选择节点 A、B 后执行合并、查找或连通判断。画布箭头指向父节点，双环表示集合根；访问路径会高亮，路径压缩时父指针会直接改变。可以关闭路径压缩进行对比，或开启自动随机合并。
