# 归并排序（Merge Sort）

归并排序是一种分治算法：把序列不断拆成更小的有序段，再把相邻有序段合并成更大的有序段，直到整个数组有序。

## 解决什么问题

它用于稳定、高效地排序大量数据。归并排序的时间复杂度不受初始顺序影响，适用于链表排序、外部排序以及需要稳定性的记录排序。代价是数组版本通常需要额外缓冲空间。

## 合并过程

两个子段各自已有序，因此只需比较它们当前未读取的首元素，把较小值写入辅助数组：

```text
while left and right both have values:
    buffer.push(smaller(left.current, right.current))
append remaining values
copy buffer back to source range
```

本演示使用自底向上的迭代版本，段长度依次为 `1, 2, 4, 8 ...`，避免递归调用并便于逐步动画。

## 复杂度

- 最好、平均、最坏时间复杂度：均为 `O(n log n)`；
- 数组实现的额外空间复杂度：`O(n)`；
- 稳定性：稳定，比较相等时优先读取左段元素。

## 演示功能

- 随机、近乎有序、逆序数据与自定义数组；
- 播放、暂停、单步、速度调节和重置；
- 分色展示左右有序段、当前读取元素和辅助数组；
- 实时统计比较次数、写回次数和当前段长度。
