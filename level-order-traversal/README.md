# 二叉树层序遍历 Level Order Traversal

## 算法是什么

显示队列入队出队并逐层访问二叉树节点

## 解决什么问题

按节点深度从浅到深遍历树，用于层级统计、最短层数和序列化。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

时间 O(n)，队列空间 O(w)
