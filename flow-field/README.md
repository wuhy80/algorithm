# Perlin 噪声流场 Flow Field

流场为平面中每个位置分配一个方向向量。使用 Perlin 噪声生成连续变化的方向后，相邻位置的向量具有相关性，大量粒子因此会形成平滑、自然的流线，而不是完全随机的抖动。

## 解决什么问题

连续噪声流场常用于程序化动画、风场和水流可视化、粒子特效、生成艺术以及运动纹理。Perlin 噪声本身也广泛用于地形、云层和材质生成。

## 本演示

- 使用带种子排列的三维 Perlin 噪声，其中第三维作为时间。
- 支持 300 至 9000 个粒子，并使用 TypedArray 连续存储状态。
- 可调节噪声尺度、方向旋度、时间演化、速度与轨迹衰减。
- 支持显示向量网格以及鼠标涡旋、吸引和排斥力场。
