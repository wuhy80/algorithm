# 集合与映射 ADT Set / Map

## 算法是什么

演示唯一键集合、键值映射及增删查操作的语义差异

## 解决什么问题

快速维护唯一元素、成员关系和从键到值的关联，是去重、计数和索引的基础。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

哈希实现平均插入 / 删除 / 查询 O(1)
