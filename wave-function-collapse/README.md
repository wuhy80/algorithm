# 波函数坍缩（Wave Function Collapse）

波函数坍缩（WFC）是一类基于局部约束的生成算法。它把每个网格单元看作一组尚未确定的候选瓦片，反复选择信息量最小的单元，将其确定为一个瓦片，再把结果传播给相邻单元。算法名称借用了量子力学中的“叠加态”和“坍缩”概念，但它本质上是约束求解与加权随机选择。

## 解决什么问题

WFC 适合生成“局部连接正确、整体形态多样”的离散内容，例如：

- 游戏中的地图、道路、迷宫、建筑平面和地牢布局；
- 纹理、像素画、拼花与程序化图案；
- 满足接口约束的电路、水系或管线网络；
- 需要从少量局部规则扩展出大规模结构的原型设计。

它解决的核心问题是：如何只描述相邻元素之间的兼容关系，就自动合成一个完整且尽量多样的全局布局。

## 算法过程

1. **初始化叠加态**：每个单元都持有当前瓦片集中的全部候选。
2. **最低熵选择**：计算未确定单元的加权 Shannon 熵，选择熵最低的单元。
3. **随机坍缩**：按照瓦片权重，从该单元的候选集中选出一个结果。
4. **约束传播**：检查上下左右的接口；删除不再兼容的候选，并继续向外传播。
5. **处理矛盾**：某个单元候选数变为零时，恢复最近的决策快照并尝试剩余候选；如果没有可回退决策，则重新开始。
6. 重复上述过程，直到所有单元都只剩一个候选。

加权 Shannon 熵为：

```text
H(X) = ln(sum(w)) - sum(w * ln(w)) / sum(w)
```

权重让常见瓦片更容易出现；随机度通过“温度”调整权重差异，同时为相近熵值增加少量随机扰动。

## 本演示

- 三套代码绘制的瓦片：量子电路、分形水系和城市路网，无图片或网络依赖；
- 可调整 12×12 至 48×48 网格、坍缩速度、随机度和开放/封闭边界；
- 实时显示最低熵选择、传播结果、平均熵、完成比例与回退次数；
- 支持暂停、继续、单步、重建，也可直接点击未确定单元进行一次人工坍缩；
- 使用 `Uint16Array` 保存候选位集，以位运算完成相容性过滤；
- 支持桌面与移动端响应式布局。

## 复杂度

设网格单元数为 `N`，瓦片数为 `T`。一次最低熵扫描为 `O(N × T)`，一次传播最坏为 `O(N × T)`；本演示中 `T ≤ 16`，候选集合存入 16 位整数，因此过滤操作的常数很小。决策回退需要保存网格快照，单个快照空间为 `O(N)`。
