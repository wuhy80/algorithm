# 遗传火箭 Genetic Rockets

遗传算法通过模拟自然选择来优化候选解。本演示把每个火箭的一段推力方向序列视为染色体，根据到达目标的距离、完成时间和碰撞情况计算适应度，再通过选择、交叉与变异产生下一代。

## 解决什么问题

遗传算法适合搜索空间巨大、目标函数不连续或无法求导的问题，例如调度、结构设计、策略搜索和参数组合优化。它能够探索复杂解空间，但需要合理设计编码、适应度和遗传参数。

## 核心过程

1. 随机生成第一代基因序列。
2. 所有火箭执行相同长度的生命周期。
3. 按距离、碰撞和完成时间计算适应度。
4. 保留精英个体，选择高适应度父母并进行交叉。
5. 以小概率随机变异，生成下一代。

## 本演示

- 动态展示多代火箭绕过障碍接近目标的过程。
- 支持调节种群、基因长度、变异率、精英比例、推力和演化速度。
- 点击画布可移动目标或添加障碍。
- 实时显示代数、成功个体和当前最近距离。
