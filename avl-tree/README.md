# AVL 树

AVL 树是一种自平衡二叉搜索树。每个节点记录子树高度，并要求左右子树高度差（平衡因子 `BF`）只能是 `-1`、`0` 或 `1`。插入或删除破坏平衡时，算法通过局部旋转恢复这一约束。

## 解决什么问题

普通二叉搜索树可能因有序输入退化成链表。AVL 树用更严格的高度平衡换取稳定的查找性能，适合查找频繁、要求最坏情况延迟可控的有序集合、内存索引和符号表。

## 四种失衡与旋转

- `LL`：在左孩子的左侧增长，对失衡节点右旋；
- `RR`：在右孩子的右侧增长，对失衡节点左旋；
- `LR`：先对左孩子左旋，再对失衡节点右旋；
- `RL`：先对右孩子右旋，再对失衡节点左旋。

删除后根据孩子的平衡因子选择相同的单旋或双旋，并继续向根更新高度。

## 复杂度

AVL 树高始终为 `O(log n)`，因此查找、插入和删除的最坏时间复杂度都是 `O(log n)`。一次插入最多需要两次基本旋转；删除可能在多层祖先处继续调整。存储空间为 `O(n)`，每个节点额外保存高度。

## 本演示

- 显示每个节点的 `BF = 左高 − 右高`；
- 支持插入、查找、删除及 LL、RR、LR、RL 四种旋转案例；
- 逐步展示失衡检测、基本旋转和高度恢复；
- 支持播放、暂停、单步、速度调节和重置；
- 实时显示树高、最大平衡因子与累计旋转次数。
