# 康威生命游戏

康威生命游戏（Conway's Game of Life）是数学家 John Conway 在 1970 年提出的二维元胞自动机。它不是传统的对战游戏：没有玩家和胜负，每个细胞只根据周围八个邻居的状态决定下一代是存活还是死亡，整个网格由此自动演化。

生命游戏最有趣的地方在于，极其简单的局部规则可以产生稳定结构、周期振荡、移动物体、自我复制线索，甚至构造出通用计算机。

## 解决什么问题

生命游戏常用于：

- 研究局部规则如何形成复杂的全局行为和涌现现象。
- 教学展示元胞自动机、离散动力系统与图灵完备性。
- 探索自组织、群体演化和人工生命。
- 为游戏、艺术装置和程序化内容生成动态网格纹理。
- 验证网格模拟、并行计算和边界条件等工程实现。

它不是用来求某个数值最优解的算法，而是一个可计算系统。合适的初始图案可以充当信号、存储器与逻辑门。

## B3/S23 规则

每个细胞有八个邻居，一代中的所有细胞同时更新：

1. 死细胞恰好有 3 个活邻居时诞生，对应 `B3`。
2. 活细胞有 2 或 3 个活邻居时继续存活，对应 `S23`。
3. 活邻居少于 2 个时因孤独死亡。
4. 活邻居多于 3 个时因拥挤死亡。

```text
nextAlive = neighbors == 3 || (currentlyAlive && neighbors == 2)
```

更新必须使用双缓冲：计算下一代时只能读取完整的当前代，不能让先更新的细胞影响同一代中尚未计算的细胞。

## 经典图案

本演示内置以下结构：

- **滑翔机**：每四代向斜方向移动一个网格的周期结构。
- **脉冲星**：周期为三的大型振荡器。
- **高斯帕滑翔机枪**：第一个被发现的无限增长图案，会周期性发射滑翔机。
- **轻量级飞船**：沿直线移动的飞船结构。
- **R 五连块**：只含五个细胞，却要经过很长时间才能稳定。
- **橡实**：七个细胞组成的 Methuselah 图案，演化超过 5000 代后才稳定。

## 本项目的实现

模拟网格使用 `Uint8Array` 存储生死状态，`Uint16Array` 存储细胞年龄。当前代与下一代各有一套数组，完成整轮计算后只交换引用，动画热路径不创建细胞对象。

数组四周额外保留一圈“幽灵边界”。每代开始时统一写入环绕边界或清零封闭边界，内部循环就可以直接读取固定的八个偏移位置，不需要为每个细胞执行取模或边界判断。

渲染使用与模拟网格同尺寸的 `ImageData`，一次写入 Canvas 后再按显示尺寸放大。细胞按年龄显示为青绿、金色和珊瑚色；网格足够稀疏时会叠加细线，密集网格则自动省略以减少视觉噪声。

## 交互功能

- 在画布上拖动绘制或擦除细胞，快速设计初始状态。
- 调整网格密度与每秒演化代数。
- 在环绕世界和封闭边界之间切换。
- 调整随机存活率并重新生成随机世界。
- 加载经典图案，或将当前图案重新放置到网格中心。
- 暂停、继续、单步演化和清空画布。
- 实时查看代数、存活细胞数、变化率和帧率。

## 性能与复杂度

设网格大小为 `N = width × height`：

- 每代时间复杂度为 `O(N)`，每个细胞固定读取八个邻居。
- 空间复杂度为 `O(N)`，包括两代状态与两代年龄数据。
- Canvas 渲染复杂度为 `O(N)`，每次状态变化只提交一张像素图。

网格密度和每秒代数都会线性增加计算量。动画循环限制单帧最多追赶八代，避免页面切回前台后一次补算过多历史帧。

## 运行方式

项目零依赖，可以直接用浏览器打开 `index.html`。也可以在本目录运行静态文件服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。
