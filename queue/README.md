# 队列 Queue

队列是一种遵循 **先进先出（FIFO）** 规则的线性数据结构。元素从队尾加入，从队首移除，适合按照到达顺序处理任务。

## 解决的问题

- 任务调度、消息缓冲和打印队列。
- 广度优先搜索与树的层序遍历。
- 生产者/消费者系统中的数据传递。
- 网络请求和事件的顺序处理。

## 循环数组实现

演示使用固定容量循环数组：`head` 指向队首，`tail` 指向下一次入队位置。当指针到达数组末尾时通过取模回到开头，避免普通数组出队时移动全部元素。

## 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| Enqueue | O(1) | O(1) 额外空间 |
| Dequeue | O(1) | O(1) |
| Front | O(1) | O(1) |
| 存储 n 个元素 | - | O(n) |

## 演示操作

直接打开 `index.html`。输入数值后可以执行入队、出队和查看队首；调节容量可观察循环缓冲区重新建立，自动模式会持续生成合法操作。HEAD 和 TAIL 标记会随操作在数组中循环移动。
