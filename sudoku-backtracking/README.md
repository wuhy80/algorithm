# 数独回溯求解

数独要求在 9 × 9 棋盘中填入 1 至 9，使每一行、每一列和每个 3 × 3 宫都不出现重复数字。回溯求解把每个空格看作一个选择点：尝试合法数字，递归处理剩余空格；后续无解时撤销当前数字并尝试其他候选。

## 解决什么问题

数独求解展示了通用的约束满足问题（CSP）方法，可推广到：

- 排班、分组、资源分配和逻辑谜题。
- 组合搜索与可行解验证。
- 递归、状态修改和撤销机制。
- 启发式选择、约束传播与搜索树剪枝。

## 回溯原理

```text
solve(board):
    cell = choose an empty cell
    if no empty cell: return solved

    for digit from 1 to 9:
        if digit satisfies row, column and box:
            board[cell] = digit
            if solve(board): return true
            board[cell] = empty

    return false
```

本演示使用 MRV（Minimum Remaining Values）启发式：每次优先选择合法候选最少的空格。它更可能尽早暴露矛盾，从而减少无意义的深层搜索。

## 冲突与撤销

尝试数字时，程序检查目标格所在的行、列和 3 × 3 宫。已有相同数字会以红色标出并立即拒绝候选。合法数字以青绿色写入；如果递归搜索证明该选择无法完成整盘，数字会被清除并显示一次撤销事件。

这种“选择 → 约束检查 → 递归 → 撤销”正是回溯算法的通用结构。

## 复杂度

- 粗略最坏时间复杂度为 `O(9^m)`，其中 `m` 是空格数。
- 空间复杂度为 `O(m)`，主要来自递归深度；棋盘本身固定为 81 个格子。

实际性能远好于最坏上界，因为行、列、宫约束和 MRV 会大量剪枝。题目给定数字越少并不必然越难，关键是约束能否快速传播。

## 演示内容

- 四组不同难度的有效数独。
- 升序、降序和中心数字优先三种候选顺序。
- 播放、暂停、单步和重置求解。
- 清晰显示候选尝试、约束冲突、合法填入和回溯撤销。
- 实时显示尝试次数、已填格数、撤销次数与帧率。
