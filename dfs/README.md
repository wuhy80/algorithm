# DFS 深度优先搜索

深度优先搜索（Depth-First Search，DFS）从起点选择一条尚未探索的分支持续深入，直到目标、死路或没有新邻接点，再回退到最近仍有分支的位置继续搜索。它可以用递归调用栈实现，也可以显式维护后进先出栈。

## 解决什么问题

- 图与网格的连通性、路径存在性和遍历。
- 迷宫生成与求解。
- 拓扑排序、依赖环检测和强连通分量算法的基础。
- 树结构的前序、后序遍历。
- 回溯搜索，例如数独、N 皇后和组合枚举。

DFS 能找到路径，但在无权图中不保证路径最短。需要最少步数时通常使用 BFS。

## 算法原理

```text
dfs(node):
    mark node as visited
    if node is target: return true

    for each neighbor of node:
        if neighbor is unvisited and dfs(neighbor):
            return true

    return false  // 回退
```

本演示使用显式栈保存节点和下一条待检查的边。黄色路径表示当前调用栈，红色格是当前节点，青绿色格表示已经走过并回退的位置。

## 复杂度

使用邻接表时：

- 时间复杂度：`O(V + E)`。
- 空间复杂度：`O(V)`，最坏情况下搜索栈和访问标记都包含所有节点。

在四邻接网格中，边数与格子数同阶，所以时间和空间复杂度都可写作 `O(rows × columns)`。

## 演示内容

- 调整网格与障碍密度，生成保证起点到目标可达的随机迷宫。
- 绘制或擦除障碍，移动起点与目标。
- 播放、暂停、单步和重置搜索。
- 查看当前搜索栈、访问量、栈深度、回退次数与帧率。
- 到达目标后保留 DFS 最终找到的路径。
