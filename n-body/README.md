# N 体引力模拟（N-body Simulation）

N 体问题研究多个具有质量的物体如何在相互引力作用下运动。除极少数特殊情况外，当天体数量超过两个时通常不存在通用的解析解，因此需要把时间切成很小的步长，通过数值积分持续估算位置和速度。

## 解决什么问题

N 体模拟是计算天体物理和计算机图形学中的基础工具，常用于：

- 模拟行星、恒星和卫星的长期轨道；
- 研究星团、星系以及星系碰撞的结构演化；
- 验证多体系统中的混沌、共振和引力弹弓现象；
- 为游戏、影视和科学可视化生成近似真实的轨道运动。

它解决的不是“寻找一条最优路线”，而是“已知一组物体的初始状态，预测相互作用下的后续状态”。

## 核心模型

任意两个天体之间遵循牛顿万有引力。对天体 `i`，其他天体产生的加速度为：

```text
a_i = G * Σ m_j * (r_j - r_i) / (|r_j - r_i|² + ε²)^(3/2)
```

其中：

- `G` 是引力常数；
- `m_j` 是另一个天体的质量；
- `r` 是位置向量；
- `ε` 是软化半径，用来避免两个点极近时加速度趋向无穷。

本演示使用半隐式欧拉法（Symplectic Euler）积分：先更新速度，再用新速度更新位置。与普通显式欧拉法相比，它在轨道系统中具有更好的长期能量表现，同时计算成本较低。

## 本项目的实现

- 使用 `Float64Array` 连续存储位置、速度、加速度和质量；
- 每一帧精确计算所有天体对，并利用作用力与反作用力的对称性使每对天体只计算一次；
- 提供原行星盘、双星系统、星系相遇和球状星团四个预设；
- 可动态调整天体数量、引力常数、时间步长和引力软化半径；
- 支持持续拖尾、速度向量、暂停与场景重置；
- 在画布拖拽可发射新天体，切换“引力探针”后按住画布可临时施加强引力源；
- 实时展示帧率、天体数量和每帧计算的天体对数量。

## 复杂度

精确求解器需要检查每一对天体：

- 时间复杂度：`O(n²)`；
- 数据存储复杂度：`O(n)`；
- 每帧相互作用次数：`n(n - 1) / 2`。

这种方式适合数百个天体，并能保留所有近距离相互作用。更大规模的天体系统通常使用 Barnes-Hut 四叉树或快速多极子方法，将近似计算复杂度降低到 `O(n log n)` 或更低。

## 参数说明

| 参数 | 作用 |
| --- | --- |
| 天体数量 | 决定初始化时参与模拟的天体数 |
| 引力常数 G | 控制全部天体之间的引力强度 |
| 时间步长 | 控制每一动画帧推进的模拟时间；过大会降低稳定性 |
| 软化半径 | 限制极近距离下的最大引力，减少数值爆炸 |

## 运行方式

项目零依赖，可直接用浏览器打开 `index.html`。也可以在仓库根目录启动静态文件服务：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/n-body/`。
