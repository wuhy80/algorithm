# Boids 群鸟算法

Boids 是 Craig Reynolds 在 1986 年提出的群体行为模拟算法。名称来自 “bird-oid object”，意思是“类似鸟的对象”。它不为整个鸟群规划统一路线，而是让每个个体只观察附近邻居并执行少量局部规则，最终形成自然的集群、分散、转向和迁徙行为。

## 解决什么问题

Boids 用于模拟大量自主个体的群体运动，适合解决以下问题：

- 游戏和动画中的鸟群、鱼群、兽群或无人机编队。
- 群体机器人与多智能体协同的行为验证。
- 复杂系统中“局部规则产生全局秩序”的教学与研究。
- 不依赖预设轨迹的自然群体运动生成。

Boids 主要解决的是“如何用简单、分布式的局部决策，生成可信的群体运动”。它不是路径规划或全局最优算法；需要避障、寻路或任务分配时，通常要与其他算法组合。

## 三条核心规则

每个个体只计算感知半径内的邻居，并组合三种转向力：

### 1. 方向同步 Alignment

让当前个体的速度方向趋近邻居的平均速度方向，使鸟群逐渐朝同一方向移动。

```text
alignment = average(neighbor.velocity) - self.velocity
```

### 2. 群体聚合 Cohesion

让当前个体靠近邻居的平均位置，避免鸟群无规律地散开。

```text
cohesion = average(neighbor.position) - self.position
```

### 3. 个体分离 Separation

当邻居距离过近时产生反向作用力，避免个体重叠和碰撞。距离越近，排斥力越强。

```text
separation += (self.position - neighbor.position) / distance²
```

最终加速度由三种规则按权重合成，并受最大转向力约束：

```text
acceleration =
  alignment  * alignmentWeight +
  cohesion   * cohesionWeight +
  separation * separationWeight
```

## 本项目的实现

演示使用 Canvas 2D 实时绘制，并提供以下能力：

- 40 至 1200 个个体的动态数量调节。
- 感知半径、最大速度、转向力度和三种行为权重调节。
- 自然迁徙、紧密集群、湍流风暴和舒缓漂流预设。
- 穿越与回弹两种边界模式。
- 鼠标引导、驱散和动态障碍物。
- 运动轨迹、暂停、重组以及实时帧率与协调度指标。

核心数据使用 `Float32Array` 和 `Int32Array` 连续存储，减少对象与内存分配。邻居搜索使用空间哈希网格：每一帧先把个体写入网格，再只检查当前网格及周围网格中的候选邻居。

## 性能与复杂度

朴素实现需要让每个个体检查所有其他个体，单帧时间复杂度为 `O(n²)`。

本实现使用空间哈希后：

- 建立网格：`O(n)`。
- 邻居查询：平均 `O(n · k)`，其中 `k` 是附近网格内的候选数量。
- 内存复杂度：`O(n + g)`，其中 `g` 是网格单元数量。

当个体分布相对均匀时，`k` 远小于 `n`，因此能在浏览器中高效模拟上千个个体。若所有个体集中在同一网格内，最坏情况仍可能退化到 `O(n²)`。

## 运行方式

无需安装依赖或启动服务，直接使用浏览器打开 `index.html` 即可。

也可以在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 参数说明

| 参数 | 作用 |
| --- | --- |
| 鸟群数量 | 控制同时参与模拟的个体数量 |
| 感知半径 | 控制每个个体可发现邻居的范围 |
| 最大速度 | 限制个体的最高移动速度 |
| 方向同步 | 控制个体跟随邻居方向的强度 |
| 群体聚合 | 控制个体靠近群体中心的强度 |
| 个体分离 | 控制近距离排斥的强度 |
| 转向力度 | 限制每帧方向变化的幅度 |

权重没有唯一正确值。感知半径和聚合权重过大时，鸟群更容易形成紧密团簇；分离权重过大时，群体会变得松散；速度和转向力度同时较大时，运动会更剧烈。
