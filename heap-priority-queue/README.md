# 堆与优先队列（Heap / Priority Queue）

二叉堆是一棵用数组保存的完全二叉树。最大堆保证每个父节点不小于孩子，最小堆保证父节点不大于孩子，因此最高或最低优先级元素始终位于索引 `0`。

数组索引之间的关系为：

```text
parent(i) = floor((i - 1) / 2)
left(i)   = 2i + 1
right(i)  = 2i + 2
```

## 解决什么问题

优先队列用于任务调度、事件模拟、Dijkstra/A* 搜索、Top-K、流式数据和堆排序。它不维护全局有序，而只高效维护“当前最优先”的元素。

## 核心操作

- **入队/插入**：追加到数组末尾，与父节点比较并不断上浮；
- **提取堆顶**：保存根值，用末尾元素替换根，再选择更优的孩子不断下沉；
- **查看堆顶**：直接读取数组索引 `0`，不修改结构。

## 复杂度

查看堆顶为 `O(1)`；插入和提取为 `O(log n)`；从任意数组自底向上建堆为 `O(n)`；存储空间为 `O(n)`。

## 本演示

- 同时展示完全二叉树与底层数组的索引映射；
- 支持最大堆、最小堆、入队、提取、查看堆顶和随机队列；
- 逐步显示父子比较、上浮与下沉交换；
- 支持播放、暂停、单步、速度调节和重置；
- 实时统计元素数、堆高度与累计交换次数。
