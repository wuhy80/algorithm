# 二叉树基础 Binary Tree Basics

## 算法是什么

按层序数组构造二叉树并展示父子关系与节点定位

## 解决什么问题

用每个节点最多两个孩子的层次结构表达搜索空间、层级数据和递归分治结构。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

构建 O(n)，查找 O(n)，空间 O(n)

## 先修内容

无硬性先修要求，建议先熟悉页面中使用的基础数据结构。
