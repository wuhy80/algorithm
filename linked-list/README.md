# 单链表（Linked List）

单链表由一组离散节点组成。每个节点保存一个值和一个指向下一节点的 `next` 指针，入口由 `head` 指针保存。节点在内存中不需要连续排列，因此插入和删除只需调整相关指针。

## 解决什么问题

单链表适合频繁增删、无法预知长度或不要求随机访问的数据序列，例如队列、邻接表、哈希桶、空闲内存链和撤销记录。它用指针换取灵活的存储结构，但查找第 `i` 个元素必须从头遍历。

## 核心操作与复杂度

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| 头部插入 | `O(1)` | `new.next = head`，再更新 `head` |
| 尾部插入 | `O(n)` | 没有尾指针时需遍历到末尾 |
| 按值查找 | `O(n)` | 顺着 `next` 逐节点比较 |
| 按值删除 | `O(n)` | 找到前驱后令其跳过目标节点 |
| 存储空间 | `O(n)` | 每个节点额外保存一个指针 |

## 本演示

- 动态展示 `head`、`current`、`prev` 和 `next` 的访问及写入；
- 支持头插、尾插、按值查找和按值删除；
- 支持播放、暂停、单步、速度调节和重置；
- 实时统计节点数、比较次数和指针写入次数；
- 最多保留 12 个节点，以保证桌面和移动端的动画可读性。
