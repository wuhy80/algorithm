# 蚁群优化 Ant Colony Optimization

蚁群优化（ACO）是一类受蚂蚁觅食行为启发的概率优化算法。单只蚂蚁只依据局部信息选择路径，但群体会通过环境中的信息素间接协作：较短路径能在同样时间内获得更多往返和信息素补充，因此逐渐成为群体的主要选择。

## 解决什么问题

ACO 适合离散组合优化问题，例如旅行商问题、车辆路径规划、网络路由、任务调度和图上的最短路径搜索。它擅长在巨大搜索空间中寻找高质量近似解，但不保证每次得到全局最优解。

## 核心过程

1. 每只蚂蚁根据信息素浓度和启发式距离，以概率方式选择下一条边。
2. 完成一次有效路径后，沿途沉积与路径质量相关的信息素。
3. 所有边上的信息素持续挥发，避免早期随机选择永久占优。
4. 多轮迭代后，较短路径获得更强的正反馈并逐渐显现。

常用转移概率为：

```text
P(i → j) ∝ pheromone(i,j)^α × heuristic(i,j)^β
```

## 本演示

- 动态展示蚂蚁移动、信息素沉积与挥发。
- 支持调节蚂蚁数量、移动速度、`α`、`β`、挥发率和沉积强度。
- 随机生成连通图，并实时显示当前最优路径与成功往返次数。
- 路径颜色和宽度共同表示信息素浓度。
