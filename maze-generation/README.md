# 迷宫生成 Maze Generation

迷宫生成可以看作在网格图上构造生成树：所有单元最终连通，同时不存在环路，因此任意两点之间只有一条简单路径。本演示实现三种常见生成方法，并在完成后用广度优先搜索寻找出口。

## 三种算法

- 递归回溯：沿随机方向不断深入，遇到死路后退。通常形成较长、曲折的通道。
- 随机 Prim：从已生成区域的边界随机扩张，产生更短、更密集的分支。
- 随机 Kruskal：随机选择墙体并合并不同连通分量，使用并查集避免形成环。

## 本演示

- 动画展示开凿过程、生成前沿、BFS 搜索区域和最终路径。
- 支持调节网格大小、每帧步数、自动求解和循环生成。
- 可随时暂停或单步观察算法状态。
