# 二叉搜索树（Binary Search Tree）

二叉搜索树（BST）是一种有序树结构。对任意节点，左子树中的键都小于该节点，右子树中的键都大于该节点。这个局部规则让插入、查找和删除都可以沿一条根到叶的路径完成。

## 解决什么问题

BST 用于维护可动态增删的有序集合，支持成员查询、最小值/最大值、前驱/后继和有序遍历。它常作为集合、映射、数据库索引和更高级平衡树的基础。

## 删除规则

- 叶节点可直接移除；
- 只有一个孩子的节点由该孩子替代；
- 有两个孩子的节点用右子树最小节点（中序后继）替换，再删除原后继。

## 复杂度

设树高为 `h`：查找、插入和删除均为 `O(h)`。树较平衡时 `h = O(log n)`；按有序顺序插入会退化为链表，此时 `h = O(n)`。中序遍历为 `O(n)`，存储空间为 `O(n)`。
