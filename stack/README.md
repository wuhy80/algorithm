# 栈 Stack

栈是一种遵循 **后进先出（LIFO）** 规则的线性数据结构。元素只能从栈顶加入或移除，常用于保存暂时状态和需要逆序处理的数据。

## 解决的问题

- 函数调用栈与递归执行上下文。
- 括号匹配、表达式求值和语法分析。
- 撤销/重做、浏览器历史与深度优先搜索。
- 将输入顺序反转。

## 核心操作

- `push(value)`：将元素加入栈顶。
- `pop()`：删除并返回栈顶元素。
- `peek()`：读取栈顶但不删除。
- `isEmpty()`：判断栈是否为空。

数组实现中，使用 `top` 指向当前栈顶。压栈时增加 `top`，出栈时减少 `top`，无需移动其他元素。

## 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| Push | O(1) | O(1) 额外空间 |
| Pop | O(1) | O(1) |
| Peek | O(1) | O(1) |
| 存储 n 个元素 | - | O(n) |
