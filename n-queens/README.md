# N 皇后回溯算法

N 皇后问题要求在 `N × N` 国际象棋棋盘上放置 N 个皇后，使任意两个皇后都不在同一行、同一列或同一条对角线上。它是约束满足和回溯搜索的经典示例。

## 解决什么问题

N 皇后本身是一个组合问题，其方法可以推广到：

- 排班、资源分配和座位安排等约束满足问题。
- 数独、填字、图着色和组合生成。
- 搜索树剪枝、递归与状态撤销教学。
- 测试并行搜索、启发式排序和优化算法。

## 回溯原理

算法按行放置皇后。当前行依次尝试各列；若与前面皇后冲突则立即拒绝，安全则递归处理下一行。若下一层所有选择都失败，就撤销当前皇后并继续尝试本行后续列。

```text
solve(row):
    if row == N: return true

    for col in columns:
        if column and diagonals are safe:
            place queen at (row, col)
            if solve(row + 1): return true
            remove queen from (row, col)

    return false
```

同列冲突可用 `colA == colB` 判断；对角线冲突满足 `abs(rowA-rowB) == abs(colA-colB)`。

## 复杂度

- 最坏时间复杂度通常记作 `O(N!)`。每行只能使用尚未占用的列，对角线约束会进一步剪枝。
- 空间复杂度为 `O(N)`，递归深度、当前棋盘解和约束集合都随 N 线性增长。

若枚举所有解，必须完整遍历搜索树；本演示在找到第一个可行解后停止，以便清晰观察尝试、冲突、递归和撤销过程。

## 演示内容

- 在 4 至 12 阶棋盘间动态切换。
- 选择从左到右、中心优先或两侧交替的列尝试顺序。
- 播放、暂停、单步和重置搜索。
- 黄色问号表示安全尝试，红色连线表示与已有皇后冲突。
- 撤销事件会保留候选位置并更新回退指标。
- 实时显示尝试次数、已放置数、撤销次数与帧率。
