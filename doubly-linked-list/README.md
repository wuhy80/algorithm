# 双向链表 Doubly Linked List

## 算法是什么

同步展示 prev 与 next 指针以及双向插入、删除过程

## 解决什么问题

在已知节点位置时从两个方向遍历，并以常数时间完成局部插入或删除。

## 核心思路

演示会把算法的关键状态拆成可单步执行的快照，并同步显示当前步骤、核心指标和结构变化。可以修改左侧输入参数后重新生成过程。

## 复杂度

已知节点插入 / 删除 O(1)，按值查找 O(n)
