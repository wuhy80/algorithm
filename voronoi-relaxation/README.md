# Voronoi 图与 Lloyd 松弛

Voronoi 图把平面划分成一组区域。给定若干“站点”，每个区域包含所有离对应站点最近的点，因此任意两块相邻区域的边界都是两个站点连线的垂直平分线。

Lloyd 松弛是一种反复优化站点分布的方法：先建立 Voronoi 图，再把每个站点移向自己区域的几何质心，随后重新计算区域。多次迭代后，面积和形状会逐渐趋于均匀，形成质心 Voronoi 剖分（Centroidal Voronoi Tessellation）。

## 解决什么问题

- 将采样点均匀分布在二维区域中；
- 生成自然但尺度均衡的程序化纹理、地形和网格；
- 优化无线基站、服务设施或传感器的覆盖位置；
- 改善有限元网格质量；
- 在图形学中生成蓝噪声近似和低多边形分区。

## Voronoi 单元构造

本演示使用半平面裁剪精确构造每个单元。对于站点 `pᵢ`，先从整个画布矩形开始，再依次用“比 `pⱼ` 更接近 `pᵢ`”的半平面裁剪当前多边形：

```text
(pⱼ - pᵢ) · x ≤ (|pⱼ|² - |pᵢ|²) / 2
```

裁剪采用 Sutherland-Hodgman 算法。最终留下的凸多边形就是站点 `pᵢ` 的 Voronoi 单元。

## Lloyd 松弛

对每个单元计算精确的面积质心 `cᵢ`，然后更新站点：

```text
pᵢ ← pᵢ + λ(cᵢ - pᵢ)
```

`λ = 1` 是完整 Lloyd 步；较小的 `λ` 是欠松弛，会以更平缓的动画靠近质心。界面中的“松弛强度”就是 `λ`。

演示还通过多边形的一阶和二阶矩计算量化能量：

```text
E = Σ ∫cellᵢ |x - pᵢ|² dx
```

Lloyd 迭代通常使这项能量逐步下降。平均位移则表示站点与当前单元质心之间的平均距离。

## 功能

- 随机、聚类、环形和带状四种初始站点分布；
- 动态调整站点数量、松弛强度和动画速度；
- 自动松弛、暂停、单步执行和重新随机化；
- 显示或隐藏站点、区域填充、质心及质心连线；
- 直接拖动站点，或切换工具后点击画布添加站点；
- 实时显示量化能量、平均位移、迭代次数和帧率。

## 复杂度

当前实现为每个站点依次检查其他所有站点：

- 构造全部 Voronoi 单元：`O(n² · v)`，其中 `v` 是裁剪过程中多边形的平均顶点数；
- 质心和能量计算：`O(n · v)`；
- 站点数据：`O(n)`，生成的多边形数据通常为 `O(n · v)`。

这种直接方法适合交互式展示数百个站点，优点是代码独立且能得到真实多边形。更大规模的工程实现通常采用 Delaunay 三角剖分，在 `O(n log n)` 时间内生成 Voronoi 图。

## 运行方式

零依赖，可直接用浏览器打开 `index.html`。也可以在仓库根目录启动静态服务：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/voronoi-relaxation/`。
